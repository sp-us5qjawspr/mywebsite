# SP/US5QJA · WSPR Monitor

Бесплатный некоммерческий статический сайт для GitHub Pages. Автоматически показывает сообщения о приёме передатчика `SP/US5QJA` на нескольких диапазонах из публичной базы [WSPR.live](https://wspr.live/).

## Установка (один раз)

1. Войдите в [GitHub](https://github.com/) и создайте **публичный** репозиторий `sp-us5qja-wspr`.
2. Загрузите **содержимое** этой папки в корень репозитория, включая скрытую папку `.github/workflows/` (проще загрузить через Git или GitHub Desktop; веб-интерфейс может требовать ручного создания скрытых каталогов).
3. В репозитории откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Откройте вкладку **Actions → Update WSPR and deploy Pages → Run workflow** и запустите обновление.
5. После успешного выполнения сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/sp-us5qja-wspr/`.

GitHub Actions запускает обновление каждый час (по UTC, в 17 минут), а также при ручном запуске и изменении ветки main. Время запуска может задерживаться из-за нагрузки GitHub. Если WSPR.live недоступен, обновление использует сохранённые данные из репозитория, если они существуют; поскольку данные не коммитятся обратно, при повторных сбоях будет опубликована ошибка, а не выдуманные значения. Для гарантированного хранения между сборками можно позже добавить отдельное сохранение JSON в ветку данных.

## Как устроено

- `update.py` запрашивает позывной `SP/US5QJA` и диапазоны 160, 80, 60, 40, 30, 20, 17, 15, 12, 10, 6, 4 и 2 м за 24 часа, 7 дней, 30 дней.
- `.github/workflows/pages.yml` запускает скрипт и публикует сайт через официальный механизм GitHub Pages.
- `index.html`, `style.css`, `app.js` — карта Leaflet/OpenStreetMap, графики Chart.js, статистика, таблица.
- Данные запрашиваются при сборке, не из браузера пользователя. Домашний ПК можно выключать.

## Важно

- **Мощность 2 Вт не устанавливается сайтом.** Он отображает мощность из сообщений WSPR (обычно 33 dBm при 2 Вт). Фактическая RF-мощность зависит от трансивера.
- Сайт показывает сообщения приёма, а не QSO. Данные WSPR.live могут быть ошибочными, задержанными или недоступными.
- Источник данных разрешает личные некоммерческие проекты с бесплатным доступом к результатам; не злоупотребляйте запросами.
- Для изменения позывного или диапазона отредактируйте `CALL` и `BAND` в `update.py`, затем запустите workflow.
- Запросы ограничены 30 000 последними сообщениями на период; при интенсивной работе старые сообщения могут не попасть в выборку. Если запрос за 30 дней слишком большой, уменьшите LIMIT в `update.py` или временно отключите длинный период.
- Для теста локально: `python update.py` (нужен интернет), затем `python -m http.server 8000` и откройте http://localhost:8000/.

## Выбор диапазона

На сайте появился фильтр «Диапазон»: все диапазоны или отдельный диапазон. Статистика, карта, графики и таблица пересчитываются для выбранного диапазона. Если сообщений нет, отображается пустая выборка. При запросе всех диапазонов возможен лимит 30 000 последних сообщений на период.
