SP/US5QJA WSPR Monitor — версия «Карта на весь экран»

Заменить в корне GitHub репозитория airbuss09/mywebsite:
  index.html
  style.css
  app.js
  qr-site.png (если ещё не загружен)

НЕ удаляйте data/, update.py и .github/workflows/.

Карта: спутниковые изображения Esri (сторонний сервис), переключение на OpenStreetMap.
Подписи и линии — только из существующего data/spots.json.
Цвета: зелёный до 3000 км, жёлтый 3000–6000, оранжевый 6000–10000, красный более 10000.
Счётчик hits.sh считает обращения к бейджу, не уникальных посетителей.
При изменении данных обновляется только GitHub Actions workflow из прежней версии.

После загрузки дождитесь завершения Actions, затем Ctrl+Shift+R.
